# 🤖 Discord Botu

Bu proje Python ile yazılmış bir Discord botudur.

## 📌 Proje Açıklaması

Bu bot, Discord üzerinden gönderilen görselleri alır ve
eğitilmiş bir model kullanarak görselleri sınıflandırır.

Kullanıcı bir görsel gönderdiğinde bot,
görseli analiz eder ve sonucu mesaj olarak geri gönderir.

## ⚙️ Kullanılan Teknolojiler

- Python 🐍
- Discord Bot
- Görüntü sınıflandırma modeli
